# Correcciones del Entregable 2

El Entregable 3 pide resolver las observaciones del docente sobre el Entregable 2 y dejar constancia de cada una en una
tabla de trazabilidad, con la acción tomada, el lugar del libro donde quedó y la evidencia.

Los Entregables 2 y 3 se presentan juntos, en este mismo libro, en el tablero y en el repositorio. No hay observaciones
del docente sobre una entrega anterior que corregir, así que la tabla no tiene filas. Queda con su estructura, para
llenarla si llegan observaciones antes de la sustentación:

| observación del docente | acción | dónde quedó en el libro | evidencia (archivo, cifra o commit) | ¿cambia el ranking? |
|---|---|---|---|---|
| | | | | |

Si una corrección cambia algo que dependa de ella (una métrica, un orden de modelos, una prueba), se recalcula y se dice
en la última columna si cambia el ranking de las 112 combinaciones o la comparación con el modelo original.
